# Lecture 0 · Roadmap: GenAI development

## Why this program exists

- Companies need developers who can **build and deploy** GenAI systems, not just experiment with them.
- The goal is to go from **Python developer → GenAI Application Engineer**, ready for real industry use cases.

## What you'll master

| Area | What you'll learn to do |
|---|---|
| Core GenAI concepts | Understand LLMs, transformers, prompt design and GenAI architecture |
| APIs and models | Use OpenAI, Gemini, Ollama and Hugging Face models **interchangeably** |
| LangChain and LangGraph | Orchestrate LLM pipelines, build tools, create agentic workflows |
| RAG systems | Connect private knowledge bases to build context-aware assistants |
| Deployment and integration | Build web apps with Streamlit/Gradio; manage local or cloud deployments |

## Program structure (flexible)

| # | Module | Theme | Core focus |
|---|---|---|---|
| 1 | GenAI foundations | LLMs, transformers, APIs, chatbots | The fundamentals; build your first chatbot |
| 2 | Prompt systems and structured output | Prompt engineering, output parsing | Reusable prompt systems and data-safe outputs |
| 3 | LangChain essentials | Chains, runnables, tools | Compose LLM workflows modularly |
| 4 | RAG and knowledge integration | Retrieval-augmented generation | Let the LLM "use your data" |
| 5 | Agents and autonomy | Tools, decision-making, multi-step reasoning | AI that can plan, act and think in context |
| 6 | Agentic workflows with LangGraph | State, orchestration, control flow | Complex multi-agent systems |
| 7 | End-to-end projects | AI assistants and copilots | Production-ready apps with a UI |
| 8 | Portfolio capstone | AI developer portfolio assistant | A signature project for your resume and GitHub |

## Projects you'll build

| Stage | Project type | Outcome |
|---|---|---|
| Early | Chatbots and assistants | Working apps powered by OpenAI and local models |
| Mid | LLM pipelines (LangChain) | Automated summarization, rewriting, knowledge Q&A |
| Advanced | RAG + agents + LangGraph | Assistants that plan, recall and act |
| Final capstone | AI developer portfolio assistant | Combines memory, multiple LLMs and a UI |

Every project practises three production habits: **modular design, prompt reuse and output validation**.

## What makes the approach different

- **Project-based:** build real apps, not slideshows.
- **Developer-centric:** no data-science or heavy maths prerequisites.
- **Production practices:** how real AI teams build GenAI systems.
- **Tool-agnostic:** switch between APIs, local models and frameworks.
- **Resume-ready:** every capstone is GitHub-friendly and portfolio-worthy.

## By the end you should be able to

- Build production-grade GenAI apps with OpenAI, Gemini and local models.
- Design prompt systems, chains, tools and RAG workflows.
- Create agents that plan, recall and act.
- Integrate GenAI into UIs, APIs and full-stack apps.
- Apply for **GenAI Developer, LLM Engineer or AI Application Engineer** roles.

## Key takeaway

> "You're not learning how AI thinks — you're learning how to think *with* AI."

As a developer you **orchestrate** models (prompts, pipelines, tools, data), you don't train them from scratch.
