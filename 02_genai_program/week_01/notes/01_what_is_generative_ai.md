# Lecture 1 · What is Generative AI?

## Definition

**Generative AI** is AI that **creates new content** (text, images, code, audio, video) instead of only analyzing existing data.

| Question type | Example | Kind of AI |
|---|---|---|
| "Is this email spam?" | Predicts a label | Traditional AI |
| "Write me an email draft." | Produces something new | Generative AI |

## Traditional AI vs Generative AI (in short)

| | Traditional AI | Generative AI |
|---|---|---|
| Focus | Classification, prediction, detection | Creation, composition, synthesis |
| Examples | Predicting house prices, detecting fraud | Writing an article, generating images, composing music |

Lecture 2 compares them in detail.

## Why GenAI is exploding in popularity

- **Better LLMs:** models such as GPT-5.1, Claude and Gemini write with near-human fluency.
- **Accessibility:** APIs make cutting-edge models usable without deep ML skills; a few lines of Python is enough.
- **Productivity:** automates repetitive work and speeds up creative work.
- **Global adoption:** education, marketing, healthcare, software, finance, law.
- **Hype:** fast-improving tools plus media coverage brought it into the mainstream.

## Well-known tools and platforms

| Category | Examples |
|---|---|
| Text generation | ChatGPT, Claude, Gemini, LLaMA |
| Image generation | DALL·E, Midjourney, Stable Diffusion |
| Code generation | GitHub Copilot, CodeWhisperer, Replit AI |
| Audio and video | ElevenLabs (voice), Sora (video), RunwayML (video editing) |
| Multimodal | GPT-4 (text + vision), Gemini (multimodal reasoning) |

**Multimodal** means one model handles several kinds of input or output, for example reading an image and answering in text.

## Real-world use cases

- **Content creation:** blogs, marketing copy, ad campaigns.
- **Software development:** code completion, bug fixing, documentation.
- **Customer support:** chatbots, automated ticket resolution.
- **Healthcare:** clinical note drafting, drug-discovery research.
- **Education:** personalized tutoring, study guides.
- **Business operations:** meeting summaries, report drafting, data analysis.

## The future

- **Democratization:** non-engineers using powerful AI tools every day.
- **New roles:** AI product managers, prompt engineers, AI auditors.
- **Risks and ethics:** deepfakes, misinformation, copyright disputes (see Lecture 4).
- **Long-term:** AI agents working alongside people, reimagined workflows, large productivity gains.

## Key takeaways

- Generative AI = AI that **creates**, not just analyzes.
- Tools like ChatGPT, DALL·E and Copilot are already mainstream.
- It's changing industries and job roles.
- Big opportunities come with real ethical challenges.
